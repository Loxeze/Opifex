# 2.4.1 — Chiusura task con controllo di consegna
- Per i progetti con una buona pratica/checklist (es. i video), un agente non può portare una task a «completata» senza un controllo di consegna riuscito (`consegna_verifica`) nelle ultime 24 ore. Se manca o è bloccato, la chiusura viene rifiutata con le istruzioni.
