# 1.82.3
- **numpy**: il requisito è ora «numpy>=1.26» (prima era fissato alla 2.5.4, che alcuni server non riescono a installare). Se una libreria con versione fissa non esiste per il Python del server, l'installazione automatica all'avvio riprova con la più recente compatibile. Risolve «No module named 'numpy'».
