# Opifex 2.60.1 — Gli agenti passano i canali YouTube a Padre Casati

- **Niente chiavi YouTube.** Aurora chiedeva una chiave YouTube Data API per leggere il catalogo di un canale: non serve. Padre Casati legge i canali da solo, dai sottotitoli.
- **Gli agenti possono passargli un canale.** `chiedi_competenza` ha un campo nuovo, «canale» (link o nome).
  - Se il canale è già in studio, l'agente lo sa subito.
  - Se è nuovo, finisce fra le proposte in Squadra → Padre Casati → Da studiare: lo approvi con un clic.
- Gli agenti hanno l'indicazione esplicita di non chiedere chiavi API per YouTube.
