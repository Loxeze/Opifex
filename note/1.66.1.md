# 1.66.1 — Aggiornamento di sicurezza: Pillow 13.0.0

- Il controllo settimanale delle librerie (1.63.0) ha segnalato vulnerabilità note in Pillow 12.3.0. Aggiornato a 13.0.0 (la 12.3.0 è l'ultima della serie 12). Pillow serve solo a ridimensionare le immagini prima di farle leggere all'AI: nessuna modifica di comportamento.
- Dopo l'installazione l'avviso scompare al prossimo controllo («Controlla adesso» in Impostazioni → Sistema → Controllo delle librerie).
