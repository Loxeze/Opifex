# 2.12.2 — Google: «non raggiungibile» non resta più appeso all'account

- Se il server perde la rete per un attimo, le chiamate a Google (collegamenti, Drive, Gmail, Calendar) ora si ripetono da sole fino a 3 volte prima di dare errore.
- L'errore scritto sotto la mail nella scheda Collegamenti si cancella da solo al primo accesso riuscito: prima restava finché non si ricollegava l'account.
- Se compare ancora, premi «Prova»: se anche così risulta irraggiungibile, il problema è la rete del server (DNS o uscita), non l'account.
