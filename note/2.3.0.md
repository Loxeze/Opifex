# 2.3.0 — Memoria condivisa delle buone pratiche

- Quando archivi un progetto, scheda, decisioni (anche quelle superate) ed esiti dei task diventano una **buona pratica**: cosa funziona, cosa evitare, checklist. La scrive un modello economico (solo se i dati interni possono uscire), altrimenti la compone Opifex dalla scheda.
- Gli agenti la usano: all'avvio ricevono le 3 più vicine al loro progetto e possono cercarne altre con il nuovo strumento `best_practice_cerca`.
- Progetti → «Buone pratiche condivise»: leggi, correggi o scarta; una scheda rivista da te non viene più riscritta. Su ogni progetto c'è «Ricava buona pratica» per generarla subito.
