# 1.84.2 — Archivio NAS: dice perché una cartella risulta vuota

Il programma sul NAS (1.3) ora spiega accanto alla cartella perché non trova file:
- cartella VUOTA per il contenitore (percorso di `volumes` inesistente o sbagliato: Docker ne crea una vuota);
- cartelle non leggibili (permessi);
- file presenti ma di tipi non riconosciuti (con le estensioni viste);
- sottocartelle senza file.
Una cartella a zero file non cancella più nulla dal catalogo.
