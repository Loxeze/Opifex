## 1.47.0 – CRM, prima tappa
- Pulsante «Importa contatti» sempre visibile in CRM; importazione guidata in 3 passi: file → anteprima e abbinamento delle colonne → controllo doppioni (senza salvare) → report con le righe saltate.
- Doppioni: salta, completa i contatti già presenti, oppure importa comunque; ricerca nella lista o in tutte le liste.
- Nuovo Cruscotto (pagina iniziale del CRM): numeri chiave, imbuto di vendita, valore previsto, tasso di vittoria, scadenze, ricontatti, attività recente.
- Opportunità a colonne: si trascinano da una fase all'altra (o dal menu su ogni scheda).
