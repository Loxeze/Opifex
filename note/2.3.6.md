# 2.3.6 — «Installa ffmpeg ora»
- Se la diagnosi dice che ffmpeg manca, in Impostazioni → Collegamenti → «Trascrizione dei video» c'è il pulsante **Installa ffmpeg ora**: scarica ffmpeg accanto ad Opifex, senza sudo e senza toccare il server. Dopo, «Controlla / prova» deve mostrare ffmpeg ✔.
- La diagnosi ora dice anche il motivo preciso quando ffmpeg non parte.
